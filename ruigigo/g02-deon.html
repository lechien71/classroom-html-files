似ている表現の使い分け 02

살던 と 살았던 と 산

どれも「住んでいた〜」。思い出し方が違う|『新・韓国語へのとびら』13A・12B

1日本語なら、どれも「住んでいた町」

子どものころの町を友達に紹介するとき、日本語なら「私が住んでいた町」の1つで済みます。韓国語では次のような言い方があります。

내가 살던 고향 내가 살았던 고향

どちらも「私が住んでいたふるさと」です。でも、韓国語では過去の思い出し方が少し違います。さらに過去連体形の 산 も関係してきます。

このページでは、色を次のようにそろえています。

Ⅰ-던 Ⅲ-ㅆ던 Ⅱ-ㄴ(過去連体形)

2ひとことで言うと

Ⅰ-던 → 「(ずっと/途中まで)〜していた」

しばらく続いていたこと、途中だったことを、その場面に戻って思い出す。動画を再生するイメージ。

Ⅲ-ㅆ던 → 「〜した/〜だった」

もう終わったこととして振り返る。今とは切れている感じ。アルバムの写真を見るイメージ。

Ⅱ-ㄴ → 「〜した」

過去の事実をそのまま言うだけ。思い出す気持ちは弱め。

  • 먹던 빵 は「食べかけのパン」。途中で止まっている感じが出ます。
  • 먹었던 빵 は「(前に)食べたパン」。食べ終わったこととして思い出しています。
  • 形容詞・指定詞の過去は Ⅲ-ㅆ던 がふつうです(예뻤던、학생이었던)。

3形の作り方

던 は活用形Ⅰに、ㅆ던 は活用形Ⅲに、ㄴ は活用形Ⅱに付きます。

  • 살다 はㄹ語幹なので、活用形Ⅱに ㄴ が付くと ㄹ が落ちて 산 になります。
  • 形容詞・指定詞の Ⅱ-ㄴ は現在の意味です。過去を言うときは Ⅲ-ㅆ던 を使います。( )の Ⅰ-던 の形もありますが、会話ではあまり使いません。
  • 母音で終わる名詞の指定詞は縮まって 친구였던(友達だった)のようになります。

5同じ文で比べてみよう

① ふるさとの写真を見せながら

여기가 제가 살던 고향이에요. そこで毎日を過ごしていたころの景色が、ふっとよみがえるような言い方です。思い出の中に入っていく感じがあります。
여기가 제가 살았던 고향이에요. 「前に住んでいたふるさと」と、もう終わった過去として振り返っています。「今はもう住んでいない」ことがはっきり伝わります。

会話ではどちらもよく使い、違いはわずかです。迷ったら 살았던 を使うと安心です。童謡「故郷の春」の歌い出し 나의 살던 고향은(私の住んでいたふるさとは)も 던 です。

② 机の上のパンを指さして

이거 제가 먹던 빵이에요. 「これ、私の食べかけのパンです(食べないでね)」。食べている途中で止まっています。
이거 지난번에 먹었던 빵이에요. 「あ、これ、この前食べたパンだ!」。食べ終わった出来事として、そのときを思い出しています。
이거 지난번에 먹은 빵이에요. 「これ、この前食べたパンです」。食べたという事実を伝えるだけで、思い出す気持ちは弱めです。

実際の会話では 아까 먹었던 빵(さっき食べたパン)のように、먹은 の代わりに 먹었던 を使う人がとても多いです。どちらも自然です。

③ 大学時代の話をしていて

대학 때 자주 가던 카페가 없어졌어요. 「よく通っていたカフェ」。通い続けていたころの日常が目に浮かびます。
대학 때 자주 갔던 카페가 없어졌어요. 「よく行ったカフェ」。大学時代を「もう終わった時期」として振り返っています。意味はほとんど同じです。

6片方だけが自然な例

飲みかけのコーヒーがなくなっていて
○어? 제가 마시던 커피 어디 갔어요?
×어? 제가 마신 커피 어디 갔어요?
「飲みかけ」を表せるのは Ⅰ-던 だけです。마신 だと「飲み終わったコーヒー」になり、場面に合いません。
○어제 처음 만난 사람이에요.
×어제 처음 만나던 사람이에요.
「初めて会った」は1回で終わった出来事です。続いていたことを表す Ⅰ-던 は合いません。
○어렸을 때 진짜 작았던 우리 강아지
×어렸을 때 진짜 작은 우리 강아지
形容詞の 작은 は「(今)小さい」という現在の意味です。「小さかった」と過去を言うには 작았던 を使います。
○고등학교 때 반장이었던 친구
△고등학교 때 반장이던 친구
指定詞の過去も Ⅲ-ㅆ던 がふつうです。이던 も間違いではありませんが、会話ではあまり聞きません。
子どものころ住んでいた家を見せて
○여기가 제가 어릴 때 살던 집이에요.
△여기가 제가 어릴 때 산 집이에요.
산 は 사다(買う)の過去連体形と同じ形です。제가 산 집 は「私が買った家」と聞こえやすいので、「住んでいた家」なら 살던 か 살았던 を使います。

8練習問題

自然なほうを押してください。正解と解説が出ます。

机の上に、少しだけ飲んだジュースがあります。Q1. 그거 제가 ( ? ) 주스예요. 버리지 마세요!

飲んでいる途中、つまり「飲みかけ」なので Ⅰ-던 です。

Q2. 이 사람은 어제 미팅에서 처음 ( ? ) 사람이에요.

「初めて会った」は1回で終わった出来事です。Ⅱ-ㄴ の 만난 が自然です(만났던 も言えます)。

今はすっかり大きくなった犬の、子犬のころの写真を見て。Q3. 와, 이때 진짜 ( ? ) 우리 강아지!

形容詞の 귀여운 は「(今)かわいい」です。「この時かわいかった」と過去を言うので Ⅲ-ㅆ던 を使います(귀엽다 はㅂ変則で 귀여웠던)。

「住んでいた家」と言いたいとき。Q4. 여기가 제가 초등학생 때 ( ? ) 집이에요.

산 집 は「買った家」と聞こえやすいので、살던(または 살았던)を使います。

高校のときクラス委員だった友達。今はもう違います。Q5. 고등학교 때 반장( ? ) 친구가 다음 주에 결혼해요.

반장인 だと「今クラス委員である」になります。過去のことなので指定詞の Ⅲ-ㅆ던、반장이었던 です。
