似ている表現の使い分け 04

Ⅲ-서 と Ⅱ-니까

どちらも「〜から・〜ので」。後ろに来る文で決まる|『新・韓国語へのとびら』14-B・21-B

1日本語なら、どちらも「〜から」

理由を言うとき、日本語では「〜から」「〜ので」を使います。

「風邪をひいたので行けませんでした」
「時間がないから急ぎましょう」

韓国語では、この2つを違う形で言います。

감기에 걸려서 못 갔어요. 시간이 없으니까 빨리 가요.

2つ目を ×시간이 없어서 빨리 가요 と言うと、不自然になります。なぜなのか見ていきましょう。色は次のようにそろえています。

Ⅲ-서 Ⅱ-니까 Ⅰ-거든요

2ひとことで言うと

Ⅲ-서 → 自然な因果・事実の報告

「〜して(その結果)〜」。後ろに勧誘・命令は来ない。

Ⅱ-니까 → 話し手の判断としての理由

「〜だから(〜しよう/〜して)」。後ろに勧誘・命令がよく来る。

  • Ⅲ-서 は前と後ろの因果関係がとても強く、話し手の気持ち(主観)を挟む隙間がありません。だから「〜しよう」「〜して」とは結びつきません。
  • Ⅱ-니까 は「私はこう判断する」という理由です。相手に何かを勧めたり頼んだりするときにぴったりです。
  • Ⅰ-고 は理由を表せません。×시간이 없고 못 갔어요 → ○시간이 없어서 못 갔어요

あわせて覚えたい

Ⅰ-거든요 → 「〜なんですよ」。先に結論を言って、理由をあとから付け足します。聞き手に事情を分かってもらう言い方です。

3形の作り方

서 は活用形Ⅲに、니까 は活用形Ⅱに、거든요 は活用形Ⅰに付きます。

基本形Ⅲ-서Ⅱ-니까Ⅰ-거든요
없다Ⅰ-없 / Ⅱ-없으 / Ⅲ-없어없어서없으니까없거든요
바쁘다으語幹 Ⅲ-바빠바빠서바쁘니까바쁘거든요
춥다ㅂ変則 Ⅱ-추우 / Ⅲ-추워추워서추우니까춥거든요

学生だ名詞+이다학생이라서학생이니까학생이거든요
  • ㄹ語幹は活用形Ⅱで ㄴ の前の ㄹ が落ちるので、멀다 → 머니까 になります。
  • Ⅲ-서 の前には過去の -았/었- を付けません。Ⅱ-니까 と Ⅰ-거든요 には付けられます。
  • 名詞のときは、会話では 학생이라서(母音で終われば 친구라서)の形をよく使います。

5同じ文で比べてみよう

① 誘いを断るとき

알바가 있어서 오늘은 못 가요. 「バイトがあるので、今日は行けません」。事情をそのまま説明しています。断るときにいちばん角が立たない言い方です。
알바가 있으니까 오늘은 못 가요. 「バイトがあるんだから、今日は行けないよ」。話し手の判断が前に出て「分かるでしょ?」という響きになり、少しきつく聞こえることがあります。
오늘은 못 가요. 알바가 있거든요. 「今日は行けないんです。バイトがあるんですよ」。先に結論を言って、理由をあとから付け足しています。会話でとてもよく使います。

② 雨の日

비가 와서 집에서 영화 봤어요. 「雨が降ったので、家で映画を見ました」。出来事の流れを、そのまま報告しています。
비가 오니까 집에서 영화 봐요. 「雨が降ってるから、家で映画見ようよ」。봐요 が「見ましょう」という勧誘になっています。Ⅱ-니까 ならこの使い方ができます。

6片方だけが自然な例

○시간이 없으니까 빨리 가요.
×시간이 없어서 빨리 가요.
後ろが「急ぎましょう」という勧誘です。Ⅲ-서 の後ろに勧誘・命令は来ません。
○곧 수업 시작하니까 자리에 앉으세요.
×곧 수업 시작해서 자리에 앉으세요.
後ろが「座ってください」という命令なので Ⅱ-니까 です。
○늦어서 죄송해요.
×늦으니까 죄송해요.
謝る・お礼を言うときの決まった形です。도와줘서 고마워요(手伝ってくれてありがとう)も同じです。
○시간이 없어서 못 갔어요.
×시간이 없고 못 갔어요.
Ⅰ-고 は理由を表せません。「〜して、それで」という因果は Ⅲ-서 で表します。
○어제 늦게 자서 너무 졸려요.
×어제 늦게 잤어서 너무 졸려요.
昨日のことでも、Ⅲ-서 の前に過去の -았/었- は付けません。

7短い会話

会話1 誘いを断る
ミノ
오늘 저녁에 같이 치킨 먹을래요?今日の夜、一緒にチキン食べない?
アヤ
아, 미안해요. 오늘은 좀 힘들어요. 내일 시험이 있거든요.あ、ごめんなさい。今日はちょっと難しいです。明日試験があるんですよ。
ミノ
아, 그렇구나. 그럼 시험 끝나고 먹어요!あ、そうなんだ。じゃあ試験が終わってから食べよう!
アヤ
좋아요! 시험 끝나면 연락할게요.いいですね!試験が終わったら連絡しますね。

まず「今日は難しい」と結論を言って、있거든요 で理由を付け足しています。

会話2 授業に遅れそう
ユジン
벌써 8시 50분이에요! 수업 9시에 시작하니까 빨리 가요!もう8時50分ですよ!授業は9時に始まるから、急ぎましょう!
ソウタ
잠깐만요, 어제 늦게 자서 너무 졸려요….ちょっと待って、昨日遅く寝たので、すごく眠くて…。
ユジン
뛰면 잠이 깰 거예요. 얼른요!走れば目が覚めますよ。早く!
ソウタ
네…. 아, 비 오니까 우산 챙겨요.はい…。あ、雨が降ってるから、傘を持っていきましょう。

「急ごう」「傘を持とう」と相手を誘う文には Ⅱ-니까。眠い理由をそのまま言うのは Ⅲ-서 です。

例감기에 걸려서 못 갔어요.시간이 없으니까 빨리 가요.내일 시험이 있거든요.

迷ったら、文の最後を見ます。「〜しよう」「〜して」で終わるなら Ⅱ-니까 です。

9練習問題

自然なほうを押してください。正解と解説が出ます。

Q1. 날씨가 ( ? ) 한강에 산책하러 가요!

後ろが「行きましょう」という勧誘なので Ⅱ-니까 です。

Q2. 과제 ( ? ) 진짜 고마워요.

お礼を言うときは Ⅲ-서 を使います。

Q3. 어제 너무 ( ? ) 친구 연락을 못 봤어요.

Ⅲ-서 の前に過去の -았/었- は付けません。

Q4. 버스가 계속 ( ? ) 그냥 택시 타요.

「タクシーに乗ろう」と誘っているので Ⅱ-니까 です。

Q5. A: 오늘 왜 이렇게 기분이 좋아요?
B: 오늘 알바비 들어오는 ( ? ).

聞かれたことに「〜なんですよ」と理由を説明しています。文の終わりなので Ⅰ-거든요 です。날이라서 だと文が途中で終わってしまいます。
