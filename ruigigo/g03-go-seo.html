似ている表現の使い分け 03

Ⅰ-고 と Ⅲ-서

どちらも「〜して」。動作がつながっているかどうか|『新・韓国語へのとびら』14-A

1日本語なら、どちらも「〜して」

週末のことを話すとき、日本語では次のように言います。

「晩ごはんを食べて、宿題をしました」
「駅で会って、一緒に行きました」

どちらも「〜して」です。でも韓国語では、この2つを違う形で言います。

저녁을 먹고 숙제를 했어요. 역에서 만나서 같이 갔어요.

違いは、前の動作と後ろの動作がつながっているかどうかです。このページでは、色を次のようにそろえています。

Ⅰ-고 Ⅲ-서

2ひとことで言うと

Ⅰ-고 → 前後は独立した動作 📦 → 📦

「Aをして(それはそれで終わり)、次にBをする」。別々のこと。

Ⅲ-서 → 前後はつながった一連の動作 🔗🔗

前の動作の結果が残ったまま、後ろの動作をする。2つで1つの行動。

숙제를 하다📦 →자다📦 숙제를 하고 잤어요.
한국에 가다🔗🔗쇼핑하다 한국에 가서 쇼핑하고 싶어요.

韓国に「行った」結果(韓国にいる状態)が残ったまま、そこでショッピングをします。宿題と寝ることは、それぞれ別の動作です。

🎬 映画の撮影にたとえると

Ⅰ-고:シーン1を撮影 → カメラを止める → シーン2を撮影
🎬 シーン1✂ カット🎬 シーン2

2つの独立したシーンです。結びつきは弱く、「1つ終わって切り替える」感じがあります。

Ⅲ-서:カメラを止めずに続けて撮る
🎬 シーン1 ━━ シーン2

ひと続きの場面です。結びつきが強く、2つで1つの行動になります。

3形の作り方

고 は活用形Ⅰに、서 は活用形Ⅲに付きます。

基本形Ⅰ-고Ⅲ-서
가다Ⅰ-가 / Ⅲ-가가고가서
먹다Ⅰ-먹 / Ⅲ-먹어먹고먹어서
만나다Ⅰ-만나 / Ⅲ-만나만나고만나서
앉다Ⅰ-앉 / Ⅲ-앉아앉고앉아서
하다Ⅰ-하 / Ⅲ-해하고해서
듣다ㄷ変則 Ⅲ-들어듣고들어서
  • Ⅲ-서 の前には過去の -았/었- を付けません。過去のことでも 가서 샀어요 のように、文末だけ過去形にします(×갔어서)。
  • Ⅲ-서 でつなぐとき、前後の動作をする人は同じです。

4どんな場面で使う?

場面Ⅰ-고Ⅲ-서
別々の動作を順番にする宿題をする → 寝る○×
移動して、その場所で何かする学校に行く → 勉強する△○
人に会って、その人と何かする△○
作った・買ったものを使って何かするパンを買う → 食べる△○
座る・立つなど、姿勢を変えてから△○
服を着る・靴をはく・帽子をかぶってから○×

○ 自然 △ 場面によっては使える・少し不自然 × 使わない

着る・はく・かぶる(입다・신다・쓰다)は、身につけたまま動いても Ⅰ-고 を使います。코트를 입고 나갔어요(コートを着て出かけました)。

5同じ文で比べてみよう

① 友達と映画

친구를 만나고 영화를 봤어요. 友達に会って(その用事は終わり)、それから映画を見ました。映画は一人で見たのかもしれません。シーンが2つあります。
친구를 만나서 영화를 봤어요. 友達に会って、その友達と一緒に映画を見ました。会ったところから映画までが、ひと続きの場面です。

② ケーキを作って

케이크를 만들고 친구한테 연락했어요. ケーキを作り終えて、それから友達に連絡しました。作ることと連絡することは別々の動作です。
케이크를 만들어서 친구한테 줬어요. ケーキを作って、そのケーキを友達にあげました。作ったものが次の動作につながっています。

③ 1つの文に両方入ることも

수업이 끝나고 집에 가서 바로 잤어요. 授業が終わって(📦 ここで区切り)、家に帰って(🔗 そのまま家で)すぐ寝ました。「家に帰る」と「寝る」はつながっています。

6片方だけが自然な例

○학교에 가서 공부해요.
△학교에 가고 공부해요.
学校に「行って、学校で」勉強します。移動した先での行動は Ⅲ-서 です。
○저녁을 먹고 숙제를 했어요.
△저녁을 먹어서 숙제를 했어요.
食べることと宿題は別々の動作です。먹어서 だと「食べたので宿題をした」と理由のように聞こえてしまいます。
○코트를 입고 나갔어요.
×코트를 입어서 나갔어요.
着る・はく・かぶるは Ⅰ-고 です。입어서 だと「着たので出かけた」という理由の意味になります。
○의자에 앉아서 기다렸어요.
△의자에 앉고 기다렸어요.
「座った状態のまま」待っています。座った結果が残っているので Ⅲ-서 です。
○편의점에서 김밥을 사서 먹었어요.
△편의점에서 김밥을 사고 먹었어요.
買ったそのキンパを食べています。手に入れたものを使う動作は Ⅲ-서 でつなぎます。

7短い会話

会話1 週末どうだった?
ジウ
주말에 뭐 했어요?週末何してたの?
ソラ
친구를 만나서 성수동에 갔어요.友達に会って、ソンスドンに行きました。
ジウ
오, 성수동 요즘 핫하잖아요! 뭐 했어요?おお、ソンスドン最近人気だよね!何したの?
ソラ
팝업 스토어 구경하고 카페에 가서 케이크 먹었어요.ポップアップストアを見て、カフェに行ってケーキを食べました。
ジウ
부럽다…. 저는 과제 하고 바로 잤어요.うらやましい…。私は課題をして、すぐ寝ました。

友達と会って一緒に行ったので 만나서、カフェに行ってそこで食べたので 가서。見物と課題は「1つ終わって次へ」なので Ⅰ-고 です。

会話2 待ち合わせの相談
ハル
내일 몇 시에 만날까요?明日何時に会いましょうか?
ミナ
열두 시에 학교 앞에서 만나서 같이 가요.12時に学校の前で会って、一緒に行きましょう。
ハル
좋아요. 그럼 점심 먹고 영화 볼까요?いいですね。じゃあお昼を食べて、映画を見ましょうか?
ミナ
네! 영화 보고 나서 노래방도 가요.はい!映画を見たあと、カラオケにも行きましょう。

会ってそのまま一緒に移動するので 만나서。お昼、映画、カラオケはシーンを切り替えながら進むので Ⅰ-고 です。Ⅰ-고 나서 は「〜し終わってから」と区切りをはっきりさせる言い方です。

8まとめ

Ⅰ-고Ⅲ-서
前後の関係独立した動作 📦 → 📦一連の動作 🔗🔗
結びつき弱い(完了・切り替え)強い(2つで1つの行動)
撮影ならカメラを止めて次のシーンカメラを止めずに続けて撮る
例저녁을 먹고 숙제를 했어요.한국에 가서 쇼핑하고 싶어요.

迷ったら「前の動作の結果が、後ろの動作まで残っているか」を考えます。残っていれば Ⅲ-서 です。

9練習問題

自然なほうを押してください。正解と解説が出ます。

Q1. 도서관에 ( ? ) 책을 빌렸어요.

図書館に行って、図書館で本を借りました。移動先での行動なので Ⅲ-서 です。

Q2. 샤워를 ( ? ) 바로 잤어요.

シャワーと寝ることは別々の動作です。해서 だと「シャワーをしたので寝た」と理由に聞こえます。

Q3. 새 운동화를 ( ? ) 산책했어요.

着る・はく・かぶるは Ⅰ-고 を使います。

Q4. 수업 끝나고 친구를 ( ? ) 같이 저녁을 먹었어요.

会ったその友達と一緒に食べています。ひと続きの場面なので Ⅲ-서 です。

Q5. 떡볶이를 ( ? ) 친구들이랑 나눠 먹었어요.

作ったそのトッポッキを分けて食べています。作ったものが次の動作につながるので Ⅲ-서 です。
